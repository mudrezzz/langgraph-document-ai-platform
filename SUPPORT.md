# Support

## 1. Где задавать вопросы

- Технические вопросы по использованию/расширению: Issues в репозитории.
- Ошибки и regressions: Issues с reproduction steps и expected behavior.

## 2. Что прикладывать в issue

1. Версия/коммит (SHA).
2. Runtime профиль (`APP_RUNTIME_PROFILE`, `APP_ASYNC_PROVIDER`).
3. Шаги воспроизведения.
4. Фактический результат и ожидаемый результат.
5. Логи/stack trace (без секретов).

## 3. Security issues

Для уязвимостей не публикуйте детали в открытом issue. Используйте процесс из `SECURITY.md`.

## 4. SLA/response expectations

Проект развивается best-effort. Для критичных production incidents держите собственный operational fallback plan.
